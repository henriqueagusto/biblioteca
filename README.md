DESCRIÇÃO DO PROJETO :
Este projeto vai além de uma lista de cadastro simples. Foi desenvolvida uma "Estante Virtual Interativa" que simula uma biblioteca física. 

DIFERENCIAIS TÉCNICOS IMPLEMENTADOS:
1. Persistência de Dados (LocalStorage): O sistema é totalmente funcional. Os livros não somem ao fechar o navegador, simulando um banco de dados real no lado do cliente.
2. Design Responsivo (CSS Grid): Utilização de Grid Layout moderno para organizar os livros automaticamente em qualquer tamanho de tela.
3. Interatividade Avançada:
   - Feedback visual 3D ao passar o mouse (CSS Transforms).
   - Tooltips dinâmicos gerados via CSS/JS.
   - Sistema de exclusão com confirmação de segurança (clique duplo).
4. Código Limpo: Estrutura semântica, uso de variáveis CSS (:root) e funções modulares no JavaScript para facilitar manutenção.

COMO TESTAR:
1. Abra o arquivo index.html em qualquer navegador moderno.
2. Cadastre um livro escolhendo título, nota e cor.
3. Atualize a página (F5) para provar que os dados persistem.
4. Passe o mouse sobre os livros para ver os detalhes.
5. Dê um CLIQUE DUPLO em um livro para testar a função de remover.
